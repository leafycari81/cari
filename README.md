# Cari's English

國中英文課堂加扣分與作業檢查紀錄系統（805 / 814 / 819）。**整個程式只有 index.html 一個檔案**，其餘是圖示。

## 上傳到 GitHub（覆蓋舊版）

repo 根目錄只需要這些：

```
index.html                     ← 程式本體（含版面樣式）
manifest.webmanifest
apple-touch-icon.png
apple-touch-icon-precomposed.png
icons/                         ← 資料夾：icon.svg / icon-180 / icon-192 / icon-512
```

**請把舊版的 app.dc.html、support.js、_ds/、ds/、app.html、根目錄零散的 icon-*.png 全部刪掉。**
（舊的 app.dc.html 若留著，Safari 可能還是載入它的快取版本。）

## 裝到平板主畫面

- iPad（Safari）：開網址 → 分享 → 加入主畫面。若之前加過舊捷徑，先刪除再重新加入。
- Android 平板（Chrome）：右上選單 → 安裝應用程式。

## 更新後看到舊畫面怎麼辦

Safari 會快取。任一方法即可：
1. 網址後面加上 `?v=2`（每次改數字）重新載入；
2. 設定 → Safari → 清除瀏覽記錄與網站資料；
3. 從主畫面刪除捷徑，重新「加入主畫面」。

## 功能

- 班級切換：805、814、819
- 每人學習態度起始 80 分；卡片顯示起始分數、加扣分正負值、目前分數
- 加分：主動發表 +2；認真練習／完成作業／完成訂正／幫助同學 +1
- 扣分：不當言語 -2；講話／做其他事／未寫作業／未訂正／未帶課本 -1
- 作業檢查：課本／講義／學習單／訂正 + 頁數範圍；點選完成者 +1、未點選者 -1；待補交名單可 +1 補回
- 統計：積分前十名、扣分最多前五位（含最常被扣原因）、最常加分／扣分項目
- 學生面板：本次段考統計、作業繳交明細、加扣分明細、最近紀錄
- 匯出 Excel（總表＋明細）與 CSV
- 段考結算歸零：單班或三班一次清空（名單保留）

## 注意

- 首次開啟需要網路（字型與執行庫從 CDN 載入），之後瀏覽器會快取。
- 資料存在該台平板的瀏覽器裡，不會同步到其他裝置；換裝置或清瀏覽器資料前請先匯出 Excel。
- 段考結算歸零無法復原，請先匯出。
